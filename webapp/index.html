How the model learns

  1. MobileNet, a pretrained vision network, turns each photo into a numeric fingerprint.
  2. Each training photo is lightly augmented (crop, flip, brightness) so the classifier sees more than one example per module.
  3. A small dense network is trained on those fingerprints, then a new photo is compared with cosine similarity.
  4. If the new photo is not close enough to either learned module, the app returns not a valid detection.
Runs entirely in your browser. Images are not uploaded to a server.
